# Sistema de Gestión de Notas

Este proyecto en Python permite gestionar estudiantes, cursos y notas académicas desde la consola. Incluye funcionalidades como agregar, buscar, actualizar, calcular promedios, deshacer acciones y ordenar notas.

## Funcionalidades

- Registro de estudiantes y sus notas
- Registro de cursos y calificaciones
- Cálculo de promedios
- Historial de acciones (deshacer)
- Revisión FIFO de notas
- Ordenamiento por burbuja e inserción

##  Requisitos

- Python 3.7 o superior
- No requiere librerías externas
